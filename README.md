## 🧠 What I Learned Today
- `return` sends a value from a function back to the caller.
- `return` immediately ends the current function execution.
- `print()` displays a value on the screen, while `return` sends a value to the caller.
- Multiple `return` statements can exist, but only the first reachable `return` executes in one function call.
- `return a, b` returns multiple values as a tuple.
- Returned values can be stored, calculated, indexed, unpacked, or used in expressions.
- `return` without a value returns `None`.
- If a function reaches the end without `return`, it implicitly returns `None`.
- A returned value is not automatically printed on the screen.
- A function can **calculate → return a value → caller receives and uses it**.

## 🔑 Core Mental Model
`print(value)` → Screen  
`return value` → Caller  
`return` → Function execution ends
